# VOIDKIN — GitHub Pages

Static VOIDKIN streetwear storefront prepared from the original `voidkin.html`.

## Publish
1. Upload the contents of this folder to the root of a GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`.
4. Save and open the GitHub Pages URL.

The site keeps the original front-end behavior and uses local browser storage for cart, theme, owner-demo settings, and local image overrides.
